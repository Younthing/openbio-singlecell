# Use domain-specific companion Plot adapters

Plots are read-only companion Adapters beside the scientific category whose result they interpret. Each consumes an immutable AnnData, canonical table, or typed artifact and returns `plot`, `summary`, and equivalent `code`; multiple views of one scientific contract share one node, while different contracts keep separate nodes. We reject a universal Plot DSL and default plots emitted by every analysis because they hide scientific semantics, make unused rendering part of expensive analysis runs, and can turn a presentation failure into an analysis failure. When a worthwhile plot needs unavailable Diagnostic evidence, the producer contract retains that evidence explicitly and the Plot adapter consumes it without recomputing the analysis.
