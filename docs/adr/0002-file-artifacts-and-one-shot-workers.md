# Use immutable File artifacts and one-shot Workers

Large workflow values are immutable File artifacts referenced only by process-local ArtifactTickets, and every scientific node invocation runs in a fresh one-shot Worker. One node run publishes all of its File artifacts atomically under one shared RunLease. This keeps AnnData, tables, models, and scientific-library workspaces out of the ComfyUI process so its memory does not grow with cached results or DAG branches; accepting full-file I/O and recomputation is preferable to retaining defensive object copies.

The RunLease owns the temporary run directory. For File artifact outputs, ComfyUI caches retain ArtifactTickets rather than file contents: a cache hit reuses a ticket without starting a Worker, and cleanup follows the final cache or running-consumer reference. ComfyUI's RAM-pressure cache is supported with an advisory because RAM pressure does not control retained disk artifact usage. Classic, None, or LRU mode is recommended.

Live mutable workflow objects were rejected because safe fan-out required expensive copies; the node registry switches to the artifact-backed contract without a live-object compatibility mode. Copy-on-write, deltas, slot stores, content addressing, and a Worker pool were also rejected because they add coordination and lifecycle complexity while retaining either shared state or long-lived Worker memory. Full files preserve straightforward inspection and failure isolation, with operating-system file caching covering repeated reads.

A Persisted artifact is the explicit durable boundary for portable File artifacts, and Persist Artifact does not create a restorable workflow value or generic Restore node. Native session-only artifacts use the official scVI or cNMF directory format, remain bound to the originating runtime session and producer's probed Python interpreter identity, and cannot be persisted or restored. Concurrent one-shot Workers remain independent and their memory use can add; OpenBio does not add a scheduler or memory budget.
